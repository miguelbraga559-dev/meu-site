# Portfólio - Antônio Miguel Braga dos Santos

Meu site pessoal, criado para aprender desenvolvimento web e reunir meus projetos como estudante de Análise e Desenvolvimento de Sistemas.

🔗 **Site:** https://miguelbraga559-dev.github.io/meu-site

## Tecnologias

- HTML5 (estrutura semântica)
- CSS3 (layout com Flexbox e responsividade com media queries)
- JavaScript (menu mobile)

## Funcionalidades

- Layout responsivo para computador e celular
- Menu de navegação com âncoras entre as seções
- Menu hambúrguer no celular, que fecha ao escolher uma seção

## Como rodar localmente

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
